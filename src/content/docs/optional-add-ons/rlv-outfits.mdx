Make use of RLV if you have multiple characters, outfits, or just a lot of clothes. The HUD will remember your outfit and ensure that you are always in character every time you log in or reset. You can follow the structure below for setting up RLV shared folders so that you can easily switch attachments on the HUD.

1. RLV Shared Folder Structure: **(see video Help > Videos > Shared Folders)**
2. Copy and paste links to attachments and not the actual attachment.
3. Folder nodes below *not* in bold are for user to label as desired.
4. Italicized folder names can be named however you like for the attachment.
5. **.on\_attach** detaches anything in the folder when attaching the items in parent folder and **.on\_detach** attaches anything in the folder when detaching the items in parent folder

## Enable character automation

RLV automation is optional. Without it, you can use the companion and manage your attachments manually.

1. Enable RLV in your viewer's preferences if the viewer supports it.
2. Turn on **Characters** mode for your account so the companion can manage attachments.
3. Set up the shared folders described above, with a base body and named outfits for each character.
4. Switch outfits, redress, or remove clothing through the in-world menu or [chat commands](/getting-started/command-line).

The companion can remove and restore clothing during scenes. It can also prevent accidental removal of the companion and base body while a scene is active.

## Pregnancy attachments

If you prepare belly attachments for each size step, the companion can swap in the matching attachment as your character's belly grows. Use the size folders shown in the shared-folder example.

If the folder setup is incorrect, the companion reports the problem so you can fix it.
