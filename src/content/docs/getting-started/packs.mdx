<Aside type="note" title="Packs has been removed">
  Pack creation, invitations, membership, and Alpha/Beta/Omega roles are no longer available. This page remains so existing bookmarks still work.
</Aside>

## Roles

The former Alpha, Beta, and Omega pack roles are retired.

<a id="create-"></a>

## Create

You can no longer create a pack.

## Invite

Pack invitations are no longer available.

<a id="members-"></a>

## Members

The former pack member list and packmate controls are no longer available.

## Leave

The former leave and leadership succession controls are no longer available.

## Packs and new births

Births inherit their traits and lineage. Pack membership and pack roles are no longer inherited.
