Open **Help** from your character's main menu to find support and learning resources. Help is available regardless of your character's abilities.

## Help menu options

| Option | What you can do |
| --- | --- |
| **Join Group** | Request an invitation to the in-world community group to talk with players and get support. |
| **Manual** | Open the documentation in your viewer. The companion also posts a link in local chat so you can use another browser or device. |
| **Discord** | Get a link to the community Discord server. |
| **Changes** | Browse recent updates, newest first. Select an entry for details and a link to the full write-up. |
| **Update** | Receive a fresh copy of the companion when a newer version is available. |
| **Videos** | Open feature tutorials in your viewer, including outfit control and customization. |
| **About** | Read about the project and its creators. |
| **Locale** | Choose the language used for the companion's menus and messages. |

## Updates and tutorials

**Update** appears only when a newer version is available. If it is absent, your copy is current.

Some tutorials show nudity or suggestive content to demonstrate a feature. The video menu identifies these tutorials.
