---

Some optional connections, such as a connected toy or character directory, open a small web page to complete linking. Follow the instructions there, then return to the virtual world. This is a one-off step, separate from the live character dashboard.

## Link a service

1. Open the relevant settings menu and choose the option to link or connect the service.
2. Review the connection details in the browser window that opens.
3. Follow that service's linking instructions on the page.
4. Check the result. The page confirms success or displays an error. After a successful connection, close the browser window and return to the virtual world.

If linking fails, read the message and start again from the same settings menu. Do not share your personal sign-in information in chat.

For the ongoing character dashboard, see [Companion web dashboard](/system-guide/companion-dashboard).
